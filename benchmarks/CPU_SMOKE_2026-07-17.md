# Measured CPU smoke benchmark — 2026-07-17

## Classification

**Measured:** end-to-end synthetic-data software smoke tests.

**Not measured:** scientific accuracy, CIFAR performance, CUDA/MPS performance, multi-GPU scaling, or cloud cost.

## Environment

- Linux x86_64 container
- Python 3.13.5
- PyTorch 2.10.0+cpu
- Torchvision 0.25.0+cpu
- CUDA unavailable
- 4.0 GB visible system RAM
- CPU thread environment constrained with `OMP_NUM_THREADS=1` and `MKL_NUM_THREADS=1`

## Interpretation

The complete proxy → halving → confirmation pipeline, persistent study database, checkpoints, leaderboard, Pareto export, reports, and plots executed. The one-step estimator is low confidence and materially underestimates these tiny studies because fixed startup, model construction, evaluation, and checkpoint serialization dominate. This is useful evidence that realistic estimates should use longer pilot runs and representative checkpoint behavior.

Accuracy values are intentionally omitted because the data were random and the scores have no scientific meaning.

Machine-readable measurements are in `cpu_smoke_2026-07-17.json`.
