# Benchmarks

Benchmark reports distinguish measured results from estimates and unavailable hardware tests.

- `CPU_SMOKE_2026-07-17.md`: measured synthetic-data CPU pipeline and estimator error.
- `cpu_smoke_2026-07-17.json`: machine-readable measurements.
- `run_cpu_smoke.sh`: reproducible commands.

Do not treat smoke-test validation accuracy as model performance.

`artifacts/` contains the small reports and real plots produced by those measured runs. Checkpoints and study databases are intentionally excluded.
